## 단계 4 — 엔진 재구현 (장기)
전략: **점진적 교체**. 원본 DLL과 같은 이름·같은 export를 가진 `NarewEngine2_Release64.dll`을 만들되,
처음에는 대부분의 함수를 원본으로 포워딩하고 서브시스템 단위로 하나씩 재구현해 교체한다.
1. 헤더 복원: `re/*.exports.demangled.txt` + `re/*.vtables.json`에서 클래스 선언 자동 생성
   (가상 함수 슬롯 순서는 vtable 덤프로 확정됨)
2. 쉬운 것부터: 파일 시스템/팩 → XML/문자열 → 수학(Vector/Matrix/Quaternion) → 리소스 매니저
3. 렌더러: D3D9 → D3D11/Vulkan 백엔드 (고해상도, 최신 GPU 대응, 32비트 메모리 한계 해소)
4. 사운드(FMOD), 물리(PhysX3)는 인터페이스만 맞추고 기존 라이브러리 유지 가능
5. 검증: 원본 DLL과 동일 입력 → 동일 출력 비교 테스트 (REA `compare_functions`, 런타임 캡처)

## 주의 사항
- 이 게임은 온라인 기능이 있다. 클라이언트 수정은 서비스 약관과 충돌할 수 있으므로
  **싱글 플레이/로컬 서버에서 시험**하고, 공식 서버에서의 사용은 각자 약관을 확인할 것.
- 원본 게임 파일 재배포 금지: 모드는 변경된 파일만 배포하고, 도구는 사용자 PC의 원본에서 작업한다.
