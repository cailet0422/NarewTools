NarewTools — 아일렛 온라인 모딩 도구 (Windows 10/11)
=====================================================

이 폴더에는 프로그램이 두 개 있습니다. 폴더째 원하는 곳에 두고 실행하세요 (설치 불필요).

  NarewStudio.exe      모드 만들기 (게임 파일은 읽기만 합니다)
  NarewModManager.exe  모드를 게임에 넣고 빼기
  NarewAgent.exe       AI 에이전트(Claude Code 등)가 NarewStudio를 직접 쓰게 하는 연결 프로그램
                       MCP 서버로 등록: 명령 = NarewAgent.exe, 인자 = mcp

1) 모드 만들기 — NarewStudio
  - 처음 실행하면 게임 폴더(IsletClient_release(x64).exe가 있는 곳)를 고릅니다.
  - 위쪽 [새 모드]로 모드를 하나 만듭니다.
  - 왼쪽 메뉴:
      리소스 편집     모든 이미지·사운드·텍스트·폰트를 찾아 바꾸기
      블록 텍스처     블록 그림(아틀라스) 바꾸기
      가구 텍스처     가구 그림 바꾸기 (3D 미리보기)
      새 리소스 추가  새 블록 / 새 가구 / 새 아이템 / 새 사운드 만들기
      GUI 편집        게임 화면의 버튼·창을 실제 그림으로 보며 옮기기, 새 그림·버튼·글자 넣기
      사운드 편집     소리 자르기·붙이기·페이드·볼륨·속도, 원래 형식 그대로 저장
      월드 에디터     맵과 건축물(프리팹)을 3D로 고치기, 내 월드(게임 저장본) 열기·캡처
                      ("캡처 창"을 띄우면 게임 중 Ctrl+Alt+S로 지금 월드를 .bwr로 저장)
                      고친 맵은 "🎮 내 월드에 적용"으로 게임에 넣기(자동 백업, "↩ 백업으로" 되돌리기)
      모델 뷰어       캐릭터·가구 모델과 애니메이션 보기, Blender(glTF)로 내보내기·가져오기
      팩 탐색기       게임 .pack 파일 풀기·만들기
      내 모드         바뀐 것 목록, [모드 매니저에 설치], 배포용 .zip 만들기

2) 게임에 넣기 — NarewModManager
  - 게임 폴더를 고릅니다.
  - 모드 .zip을 창에 끌어다 놓거나, NarewStudio에서 [모드 매니저에 설치]를 누릅니다.
  - 넣을 모드를 체크하고, 위아래로 끌어 순서를 정합니다 (위쪽이 우선).
  - 게임을 끈 상태에서 [게임에 적용]. 되돌리려면 [원본 복구].
  - 원본 파일은 처음 적용할 때 .orig로 백업해 두었다가 [원본 복구] 때 그대로 되돌립니다.

3) AI 에이전트에게 맡기기 (선택)
  - MCP를 지원하는 에이전트에 "NarewAgent.exe mcp"를 서버로 등록하면, 에이전트가 맵 편집(블록·가구 배치),
    새 블록·가구, GUI·사운드 편집까지 직접 합니다. NarewStudio 창을 켜 두면 바뀐 내용이 바로 보입니다.
  - 게임 파일을 바꾸는 일(모드 적용, 내 월드에 적용)은 에이전트가 먼저 물어본 뒤에만 합니다.

알아 둘 것
  - 3D 화면은 OpenGL 3.3이 필요합니다. 그래픽 드라이버를 최신으로 두세요.
  - 새 블록·가구, 버튼 효과음 교체는 실제 게임에서 동작을 확인했습니다. 새 아이템 효과·배경음은 아직 확인 전이니, 문제가 있으면 [원본 복구]로 되돌리세요.
  - Steam 업데이트 뒤에는 모드 매니저가 알려 주면 [게임에 적용]을 다시 누르세요.
  - 자동 업데이트: 프로그램을 켜면 새 버전을 확인합니다. [업데이트]를 누르면 받아 두었다가 프로그램을 닫을 때
    새 버전으로 바꾸고 다시 엽니다(바꾸기 전 파일은 %LOCALAPPDATA%\NarewTools\update\backup-<버전>에 백업).
    오른쪽 위 버전 버튼으로 바로 확인할 수 있고, 이 폴더는 쓰기 가능한 곳(문서 등)에 두세요.
  - 오류 기록: %APPDATA%\NarewStudio\log.txt, %LOCALAPPDATA%\NarewModManager\log.txt
  - 온라인 기능이 있는 게임입니다. 테스트는 혼자 하는 곳에서 하고, 게임 약관은 각자 확인하세요.
